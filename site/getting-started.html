SETUP / ABOUT FIVE MINUTES

From install to
first prompt.

Arena Local is a desktop companion with an optional embedded arena.ai chat panel. Prompt on Arena.ai—right inside the app or in a browser—and its Bash tool requests scoped work from this computer.

THE HAPPY PATH

Six small steps.

Start in Ask mode so changes are reviewed on your desktop. You can leave the connection stopped whenever you are not using it.

  1. 01

    INSTALL

    Download and open Arena Local

    Use the Windows x64 installer from the download page. Windows may show an unrecognized-publisher SmartScreen warning because these builds are not code-signed. Only continue if you trust the source and verify the release.

  2. 02

    SCOPE

    Choose the project folder

    Select the folder you want Arena's file tools to use. Keep unrelated or sensitive projects out of scope. File operations have path protections, but shell commands are not sandboxed.

  3. 03

    CREDENTIAL

    Save your ngrok authtoken

    Paste the authtoken from your ngrok account into Arena Local. When OS secure storage is available, the app encrypts the saved token with Electron safeStorage; otherwise it stays in memory until the app closes. This token is separate from the pairing key and is never included in the Arena prompt.

  4. 04

    CONNECT

    Start the remote connection

    Arena Local starts a temporary HTTPS tunnel to its loopback task API. The desktop interface remains local. A connection attempt can be cancelled; stopping the link revokes the URL and cancels pending approvals.

  5. 05

    PAIR

    Copy the setup prompt into Arena.ai

    Click Copy Arena setup prompt, then paste it into the Arena.ai conversation. The prompt includes the live URL and bearer key and tells Arena's Bash tool to fetch the public agent guide before making bridge requests. Keep the copied prompt private.

  6. 06

    WORK

    Request a focused task

    Start with a narrow file listing or relevant read. Enable Web tools in Settings—with native confirmation—only if the task needs public research; search queries go to DuckDuckGo and page text is returned to Arena. Review every proposed file or staged Git diff, commit message, shell command, or changing/unknown Roblox Studio call in the local approval queue. Request `git_commit` only when you explicitly want a local commit; it never pushes automatically. A GitHub push is a separate local control: save a verified classic or fine-grained PAT in Settings, review the outgoing commits, and confirm in the native dialog. Use the Settings toggles for Git and Studio MCP to block those integrations and their remote tools.

⌘

OPTIONAL · ROBLOX STUDIO MCP CLIENT

Connect the Studio you intend to use.

In the latest Roblox Studio, open Assistant → … → Manage MCP Servers and enable Studio as MCP server. In Arena Local, choose Connect Roblox Studio and review the native warning. Arena Local launches the built-in server over local stdio, then forwards tool requests through the authenticated bridge. Use list_roblox_studios to choose the intended instance; Studio-targeted calls include its studio_id. Studio tools can inspect or change open places and return their data to Arena. Ask mode gates mutating or unknown tools; Read only blocks them; No-Ask can execute them without per-action approval.

WHERE THE CHAT HAPPENS

Prompt on Arena.ai. Control on your PC.

The embedded chat is a native Chromium view of arena.ai—it loads automatically by default, and you can switch to manual loading in Settings. It never sees your Arena sign-in, and your prompts stay between you and Arena. Arena's Bash tool sends authenticated requests over HTTPS; your local app enforces the permission mode and runs allowed file, Git/process, or connected Roblox Studio tools. The bottom-left Settings screen keeps profile/instructions, appearance, GitHub-token, and integration controls local to the app.

WHEN YOU'RE DONE

Close the loop.

Stop the link from Arena Local when the work is done. No-approval mode resets when the link stops, the key rotates, the workspace changes, or the app closes.

REVOKE ACCESS

Stop or rotate

Stopping the tunnel or rotating the pairing key revokes the current instructions. Pending approvals are cancelled; an action already approved and running is not undone or interrupted.
