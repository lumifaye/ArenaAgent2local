01

How it works

Is Arena Local a separate chat app or Arena clone?

No. You keep prompting on Arena.ai. Arena Local embeds the arena.ai chat panel and loads it automatically by default; turn startup loading off in Settings if you prefer to start it manually. Arena Local never sees your Arena sign-in, and it receives authenticated requests from Arena's Bash tool for local permission controls.

Does Arena Local upload my entire workspace?

No. File contents are returned only when requested through read/search actions. Git status/diff/log output, commit results, and process names/PIDs are returned only when requested; process command-line arguments are not exposed. The app does not send every file automatically. If Web tools are enabled, search queries go to DuckDuckGo and requested page text is returned to Arena.ai. Only request material you intend to share with the Arena.ai session.

How does Roblox Studio MCP work here?

Arena Local acts as an MCP client for Roblox Studio's built-in local stdio server; it does not expose Arena Local as an MCP server. After you enable Studio as an MCP server and connect it in Arena Local, the authenticated bridge exposes its tools. Use list_roblox_studios to select the intended instance and provide its studio_id on Studio-targeted calls. Studio tools can read or change open places and some may access local asset paths or Roblox services; the selected file workspace does not confine them. The local Disable Studio MCP toggle disconnects Studio and blocks its local and remote tools. Mutating and unknown tools require local approval in Ask mode and are blocked in Read only mode.

What do the optional Web tools do?

They are disabled by default, and your choice is saved locally. After you enable Web search & scraping with a native confirmation, web_search sends your query to DuckDuckGo and returns titles/URLs/snippets; web_scrape fetches one public HTTPS page without cookies or saved credentials and returns up to 30,000 characters of plain text. The tools allow at most three active requests and 30 requests per minute, use a 12-second timeout, follow up to four redirects, and cap provider/page responses at 1.5/2 MB. Only public IPv4 destinations are fetched. Search queries and retrieved text are sent to Arena.ai; websites can see your network address. Use the local toggle to block web tools and cancel active requests. Treat the returned content as untrusted.

Why does it use ngrok?

The desktop task API listens on loopback and is not directly reachable by Arena.ai. ngrok provides a temporary HTTPS path to that API. The desktop UI itself is not tunneled.

Does Arena need my ngrok authtoken?

No. The authtoken is used by the desktop app to start the tunnel and is separate from the short-lived pairing key in the copied setup prompt. Never paste the ngrok authtoken into Arena.

02

Permissions & safety

What is the default permission mode?

Ask before changes. File reads, Git inspection, process names/PIDs, locally enabled Web tools, and known read-only Studio tools are available; file writes, Git commits, shell commands, and mutating or unknown Studio tools pause in the local approval queue until you approve or deny them. Git commits require one-time approval after a staged-diff review. Read only blocks mutations. No approval — VERY DANGEROUS runs them immediately.

Can Arena read or write outside the selected workspace?

By default, file tools are confined to the selected folder. An optional EXTREMELY DANGEROUS full-computer access scope requires two native warnings while disconnected. The remote API then has no selected workspace: every file action needs an explicit absolute path, and shell requests need an explicit absolute working directory. It can read files anywhere your OS account can access, including credentials; requested content is sent to Arena.ai. Ask still requires approval for file writes, Git commits, and mutating Studio tools; Read only blocks them. Select a separate local folder for desktop preview and Git; it does not become the remote file scope, and its path is not shared with remote file tools. If Arena needs to read a file there, provide its explicit absolute path. No-Ask can be added only through a local-only safety flow with the exact warning, a 30-second lockout, slide-to-unlock, and a final native confirmation. The combination rotates the key and requires another warning before connecting. Stopping the link, rotating the key, a failed connection attempt, or closing the app disables full-computer scope; changing the separate local folder resets No-Ask to Ask but does not disable full-computer scope.

What Git and process tools are available?

Arena can request Git status, a staged-only diff, recent commit subjects, and a process list containing names and PIDs only. Git actions require Git to be enabled and a selected local repository root; full-computer mode uses a separate local preview/Git folder, not the remote file scope. The local Disable Git toggle blocks both the workbench and remote Git requests. Status and commit operations disable configured clean/process filters; files that rely on filter normalization may appear modified in status. A local commit is limited to staged changes, shows a full diff and message for one-time approval, disables hooks/signing, and never pushes automatically. You can use Review & push to inspect outgoing commits, then confirm a GitHub push in a separate native dialog. Classic and fine-grained PATs are supported; the token is not sent to Arena or stored in Git config, the remote URL, or command-line arguments. Process command-line arguments are not returned.

Are terminal commands restricted to my selected folder?

No. Commands run with your normal OS-user permissions and can access files outside the workspace. The workspace path checks protect file tools, not the shell. Review every command; the approval gate is not an OS sandbox.

Can I pause control without changing the URL or pairing key?

Yes. Use Pause control in the live connection panel. Health checks remain available, but other authenticated requests are blocked with HTTP 423 until you resume locally. The URL and key are unchanged; requests being prepared or awaiting approval are cancelled, while an action already running may finish. For full revocation, stop the link or rotate the key.

What happens when I stop the link or rotate the key?

The tunnel URL or current bearer key is revoked, full-computer access is disabled, and pending approvals are cancelled. An action that was already approved and is running is not undone or interrupted. The local Studio MCP process remains connected until you choose Disconnect Studio in Arena Local, but it is not remotely reachable without the authenticated tunnel.

What happens in No approval mode?

File writes, staged Git commits, shell commands, and mutating or unknown Roblox Studio tools execute without a local per-action prompt. Studio tools can run Luau or change open places. No-Ask is labeled VERY DANGEROUS, requires two native confirmations, and is temporary. Combining it with full-computer access requires an additional local-only exact warning, 30-second wait, slide-to-unlock, and final native confirmation; the key rotates and connecting requires another warning. The remote API cannot enable either mode. Use Ask mode unless you understand the risks.

Are protected filenames completely invisible?

Not always. In default workspace mode, a parent-folder listing may show the name of a protected file or symlink with a LOCKED marker, but file tools will not open or follow it. Full-computer access explicitly disables those file-tool protections and is EXTREMELY DANGEROUS; otherwise, do not use shell commands to bypass them.

03

Setup & downloads

Why does Windows warn that the installer is unrecognized?

The installer is not code-signed, so Windows may show its standard SmartScreen warning. Download it only from the official GitHub release linked on this site, and check the published SHA-256 sidecar when available.

Where is the latest installer?

Use the download page. It resolves the latest published GitHub Release and shows whether a checksum sidecar is available. The release assets are hosted on GitHub.

My connection will not start. What should I check?

Confirm the ngrok authtoken was saved, that the computer has an internet connection, and that Arena Local shows the current setup state. Try stopping and starting the link again; if it still fails, copy the exact error text (without any secrets) into a GitHub issue.

Can I change the workspace while connected?

No. Stop the remote link first, then choose a different folder. Changing workspaces clears session approvals and returns no-approval mode to Ask.

Where should I report a bug?

Open a GitHub issue with the app version, operating system, steps to reproduce, and relevant logs. Remove the tunnel URL, bearer key, ngrok token, workspace content, and personal data first.
