0.1.6NOV 26, 2026 UTC
ADDED
  • Make full-computer remote file access workspace-free: require explicit absolute paths and an absolute shell working directory, while keeping desktop preview and Git on a separately selected local folder.
  • Add local Git and Roblox Studio MCP enable/disable controls that block their corresponding local workbenches and remote actions; disabling cancels pending approvals and Studio is disconnected.
  • Add locally confirmed GitHub pushes for classic and fine-grained PATs. Review outgoing commits in a native confirmation; no force-push or automatic push occurs.
  • Add local pause/resume control that preserves the tunnel URL and pairing key, cancels pending approvals, and returns HTTP 423 for non-health requests while paused; actions already running may finish.
  • Document a bounded workflow for transferring only a relevant PNG for visual inspection and deleting the temporary copy afterward.
HARDENED
  • Keep the GitHub PAT out of remotes, Git configuration, and command-line arguments; authenticate through a temporary askpass helper, verify TLS, disable mirror/follow-tags behavior, and push only the reviewed branch commit.
  • Redact local Roblox error paths from the remote tool-list response and validate push URLs as credential-free GitHub HTTPS remotes.

ADDED

  • Configure repository-local author identity and HTTPS remotes; GitHub account and repository lookup uses a token held by the desktop process and never writes credentials to Git configuration or remote URLs.

0.1.2NOV 25, 2026 UTC
ADDED
  • Support full-computer access with No-Ask only through an explicit local safety sequence: the exact warning, a 30-second lockout, slide-to-unlock, final native confirmation, and an additional warning before the remote link starts.
  • Rotate the pairing key when the combined mode is authorized; expire and invalidate unlock challenges when local access state changes, the workspace changes, or a connection starts.
  • Allow full-computer file tools to use absolute paths outside the selected workspace when explicitly enabled, while retaining text and size limits and local Ask/Read only controls.
HARDENED
  • Restrict mode-changing IPC to the trusted local Arena Local window; the remote API rejects permission/scope injection and denies combined-mode tasks without local authorization.
  • Use a monotonic clock for the waiting period and reset dangerous access modes when the connection stops, fails, the pairing key rotates, the workspace changes, or the app closes.
  • Show prominent combined-mode warnings and identify outside-workspace writes in the desktop review UI.
